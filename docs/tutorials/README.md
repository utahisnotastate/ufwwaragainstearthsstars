# Tutorials

> **In one sentence:** Step-by-step guides that let you run real astronomy calculations on your own computer.

## For young readers

These guides use a computer language called Python. You type short instructions, and the computer does the math. Ask a grown-up to help you install Python the first time. After that, you can try every guide in order.

## Who these are for

- Middle and high school students who want to try real code.
- University students and teachers running a lab.
- Amateur astronomers and professionals who want to check our methods.

## A promise about the code

Every `python` code block in these tutorials is run automatically by our test suite (`tests/test_docs_snippets.py`). If the code and the tutorial ever disagree, the tests fail and we fix it. Blocks marked `py` need the internet or optional packages, so they are not run automatically.
