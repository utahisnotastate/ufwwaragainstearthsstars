# Documentation map

> **In one sentence:** Pick the guide that fits you, then explore the disclosures, lessons and tutorials.

## For young readers

Start with the [kids' guide](audiences/kids.md). It explains everything with fun examples and safe activities. Then try [Lesson 1](lessons/l01-finding-what-we-cannot-see.md)!

## How every page works

Every page has two layers:

1. **A simple part at the top** — short sentences anyone can read, often with a "For young readers" box.
2. **A "For experts" part lower down** — equations, data, methods and references.

Every claim has an **evidence level**:

| Label | Name | Simple meaning |
|---|---|---|
| 🟢 **Level 1** | **Confirmed** | Seen and checked more than once. |
| 🔵 **Level 2** | **Strong evidence** | Good results exist; experts still discuss them. |
| 🟡 **Level 3** | **Testable idea** | Follows normal physics; not shown yet; you can test it. |
| 🟠 **Level 4** | **Long shot** | Physics allows it, but today's tools may be too weak. |
