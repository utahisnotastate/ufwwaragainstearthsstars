# Data sources

> **In one sentence:** Every disclosure uses public data; this page lists where to find it.

## For young readers

Space agencies and observatories share most of their data with everyone, for free. That means you can look at the same pictures and numbers that professional astronomers use. Here is where they live.

## Moving objects (asteroids, comets, interstellar objects)

| Source | What it has | Used in |
|---|---|---|
| [Minor Planet Center (MPC)](https://www.minorplanetcenter.net/) | All reported asteroid/comet observations, orbits, the Isolated Tracklet File (ITF), observatory codes | D11, D14, D15 |
| [JPL Small-Body Database & APIs](https://ssd.jpl.nasa.gov/) | Orbits, physical data, query tool and `sbdb.api` | D11, D14, D15 |
| [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) | High-precision positions of planets, spacecraft and small bodies | All orbit work |
| [Vera C. Rubin Observatory data releases](https://rubinobservatory.org/) | New-generation sky survey, solar-system processing | D01, D11, D14 |

## Good habits with data

- Record the **version** and **date** of every data set you download.
- Read the **documentation** and **quality flags** before you trust a number.
- Follow each archive's **citation and acknowledgment** rules.
- Archive URLs and table names change. If a link here breaks, please open an issue.
